# SkillNexis Week 1 Python Projects

This repository contains my week 1 Python projects completed during 
my internship at SkillNexis.

## Projects

### 1. Snake Water Gun Game 
A simple game where the user plays Snake, Water, and Gun against the computer.

### 2. Guess the Number
A program that generates a random number between 1 and 100 and ask the user to guess it.
It giveshints until the correct number is guessed.

### 3. Student Library System
A simple student library system created using Object-Oriented Programming(OOP).
It contains separate Library and Student classes and allows students to borrow books.

## Technologies Used 

- Python
- Ramdom module
- Object-Oriented Programming(OOP)
