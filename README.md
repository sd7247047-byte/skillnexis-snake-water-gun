# Snake Water Gun Game

This is a simple python program that allows the user to play
the Snake Water Gun against the computer.

## Rules 

Snake beats Water 
Water beats Gun
Gun beats Snake
Same choice results in a tie

## Technologies Used

Python
Random module

## How to Run

Open the project in VS code.
Run 'snake_water_gun.py'.
Enter 'snake', 'water', 'gun'.
The computer will randomly select its choice.
The winner will be displayed.
